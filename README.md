## 🚀 Deploy your own

```bash
# 1. Fork this repo
# 2. Rename it to: <your-github-username>.github.io
# 3. Edit index.html with your own info
# 4. Push to main → GitHub Pages auto-deploys
```

Enable GitHub Pages: **Settings → Pages → Branch: main → / (root) → Save**
